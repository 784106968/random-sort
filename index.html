上传名单，核对无误后随机排序

解析 txt / json 名单文件，逐条校对姓名，确认后为每人分配一个随机数，按随机数大小排出次序 —— 编辑改动会实时生效，未确认前不会进行任何抽取。

上传名单文件

支持 .txt 与 .json。单文件，最大 5 MB。

把文件拖到这里，或

txt 按换行符切分 · json 读取姓名数组

txt 格式

张三
李四
王五

每一行一个姓名。空行、行首行尾空格会自动忽略。

json 格式

[
  { "name": "张三" },
  { "name": "李四" }
]

支持字符串数组、对象数组（name / 姓名 等字段），或含 names、people、list、data 的嵌套结构。

    确认名单并分配随机数 第 3 步

    下面是将要参与排序的最终名单。点击「开始随机排序」后，每个人会获得一个互不相同的随机数。

    抽取规则

    • 随机数由浏览器加密安全随机源 crypto.getRandomValues 生成，范围 0.000000 – 0.999999。
    • 同一轮内随机数互不相同，不会出现并列名次。
    • 默认按随机数从大到小排序；结果页可切换升序，重新排序会重新抽取。
    • 返回修改名单后，本次结果作废，需重新生成。

    排序结果 第 4 步

    按随机数从大到小排序，第 1 位排在最前。

      解析规则

      • txt：以换行符为分隔，每行一个姓名，空白行忽略。
      • json：字符串数组，或对象数组中的 name / 姓名 字段。
      • 重复姓名默认保留并标记（同名可能是不同的人），可一键去重。
      • 空文件或没有有效姓名时给出提示，不会进入抽取。

      键盘优先

      • Tab 移动焦点，Enter 在名单中新增一行。
      • 所有操作均可点击完成，不依赖拖拽。
